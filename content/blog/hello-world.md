Welcome to my brand-new site at **rahulgharat.me**! 🎉

This is where I'll be writing about software engineering, things I'm building, and lessons I pick up along the way.

## How this site is built

- **Next.js** with static export
- **Tailwind CSS** for styling
- Markdown files for blog posts — this post is just a `.md` file in the repo
- Hosted for free on **GitHub Pages** with a custom domain

## Writing a new post

Adding a post is as simple as dropping a new markdown file into `content/blog/` and pushing to GitHub. The deploy workflow handles the rest.
